ModCommand (namespace Terraria.ModLoader, built-in):

public abstract class ModCommand : ModType
{
    public abstract string Command { get; }
    public abstract CommandType Type { get; }
    public virtual string Description => "";
    public virtual string Usage => "";
    public abstract void Action(CommandCaller caller, string input, string[] args);
}

SubworldSystem (namespace SubworldLibrary, built-in to SubworldLibrary):
- static bool Enter<T>() where T : Subworld  -- begins transition into subworld T; returns false if already mid-transition (safe to call, no special-casing needed)
- static void Exit()  -- begins transition back to current.ReturnDestination (default -1 = main world)
- static bool IsActive<T>() where T : Subworld  -- true if currently inside subworld T

From Plan 02 (already implemented, this plan depends on it): `BossArenaSubWorld.Subworlds.BossArenaSubworld` is the Subworld subclass to pass as the generic type argument.

CommandCaller (namespace Terraria.ModLoader, built-in) exposes `caller.Reply(string message)` for printing text back to the invoking player's chat -- use this for the check-flag command's output (do not use Main.NewText, which broadcasts to all players; Reply targets only the caller).

Vanilla field: `Terraria.NPC.downedSlimeKing` (static bool) -- the flag this phase's isolation-proof test observes. Read-only access in this plan (never write to it).

ModPlayer (namespace Terraria.ModLoader, built-in):

public class ModPlayer : ModType<Player, ModPlayer>
{
    public Player Player; // the underlying Player instance
    public virtual void PostUpdate() { }  // confirmed (source-read) to run after vanilla's own per-tick Zone* flag computation -- overrides here reliably win for that tick
}
