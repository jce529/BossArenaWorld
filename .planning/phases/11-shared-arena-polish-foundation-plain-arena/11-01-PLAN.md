<task type="auto">
  <name>Task 2: Implement ArenaBuilder static helper</name>
  <files>Subworlds/ArenaBuilder.cs</files>
  <instruction>
    Create `Subworlds/ArenaBuilder.cs` as a plain public static class with zero modded type references:
    - `PlaceBoundaryContainment(int startX, int endX, int surfaceY, int thickness, int boundaryMargin, ushort boundaryTileType)`:
      - Places solid bottom boundary slab below the main platform (`y = surfaceY + thickness + 1` to `y = surfaceY + thickness + 6` across `startX..endX`).
      - Places solid left boundary column (`x = 0..3` from `surfaceY - boundaryMargin` to `surfaceY + thickness + 6`).
      - Places solid right boundary column (`x = (endX - 4)..(endX - 1)` from `surfaceY - boundaryMargin` to `surfaceY + thickness + 6`).
      - Places solid ceiling containment slab (`y = surfaceY - boundaryMargin - 4` to `y = surfaceY - boundaryMargin` across `startX..endX`).
    - `BuildTierPlatforms(int startX, int endX, int baseSurfaceY, int tierCount, int tierSpacing, ushort platformTileType, int platformStyle = 0)`:
      - For each tier `t` from 1 to `tierCount - 1`:
        - `int tierY = baseSurfaceY - (t * tierSpacing);`
        - Fill platform row `x = startX..endX`: `Tile tile = Main.tile[x, tierY]; tile.HasTile = true; tile.TileType = platformTileType; tile.TileFrameY = (short)(platformStyle * 18);`
    - `PlaceTorchInterval(int startX, int endX, int y, int interval, int torchStyle = 0)`:
      - Along row `y - 1` above the platform or solid base, place a torch every `interval` tiles using `WorldGen.PlaceTile(x, y - 1, TileID.Torches, mute: true, forced: true, style: torchStyle)`.
      - Document with a code comment that torches are visual-only and do not alter spawn suppression (LIGHT-02).
  </instruction>
</task>
