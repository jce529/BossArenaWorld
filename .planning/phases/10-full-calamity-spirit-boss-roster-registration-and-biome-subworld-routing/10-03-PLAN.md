**Correction to 10-RESEARCH.md's read-path suggestion (confirmed via decompile this session):**
`BossDownedTracker` is `internal class BossDownedTracker : GlobalNPC` -- even though `IsBossDowned<T>()` is
declared `public static`, C# caps effective member visibility at the containing type's visibility, so
`SpiritMod.NPCs.BossDownedTracker.IsBossDowned<T>()` does NOT compile directly (same CS0122 issue already
documented for the `Downed` dictionary write path in Phase 5). However, `SpiritMod.MyWorld` (a genuinely
PUBLIC class) exposes public static wrapper properties for ALL 7 non-Infernon Spirit bosses, not just
Infernon -- `DownedScarabeus`, `DownedAncientAvian`, `DownedAtlas`, `DownedMoonWizard`, `DownedVinewrath`,
`DownedDusking` (confirmed via decompile of `SpiritMod.MyWorld`, 2026-08-14) -- so every read path below
uses these directly, zero reflection needed for reads, exactly matching `DownedInfernon`'s existing
precedent. Only the write path needs reflection (into the internal `Downed` dictionary), reusing the
`_downedField` `FieldInfo` already cached for Infernon.

    ```csharp
    // Architecture Pattern 3 (10-RESEARCH.md): generalizes Infernon's write-path reflection
    // to every Spirit boss whose downed-tracking flows through the generic
    // BossDownedTracker.OnKill(NPC) hook (confirmed: none of the 6 bosses below override
    // OnKill() themselves, and none have any WorldGen/player-scoped side effect beyond the
    // flag write -- unlike Infernon's own Hellstone tile-ring, which stays
    // Infernon-specific). Reuses the SAME cached _downedField FieldInfo established in
    // RegisterInfernon() -- do not re-reflect per boss.
    [JITWhenModsEnabled("SpiritMod")]
    private static void ApplyGenericSpiritDowned<T>() where T : ModNPC
    {
        try
        {
            var downed = (Dictionary<string, bool>)_downedField.GetValue(null);
            var instance = ModContent.GetInstance<T>();
            string key = instance.Mod.Name + "/" + instance.Name;
            downed[key] = true;
            if (Main.netMode != NetmodeID.SinglePlayer)
                NetMessage.SendData(MessageID.WorldData);
        }
        catch (Exception e)
        {
            // Same swallow-and-log discipline as ApplyInfernonDowned (05-RESEARCH.md Open
            // Question 1) -- a broken reflection lookup must never crash BossCoreItem.UseItem.
            ModContent.GetInstance<BossArenaSubWorld>().Logger.Warn(
                "SpiritIntegration: failed to set " + typeof(T).Name + " downed flag via reflection: " + e);
        }
    }
    ```
